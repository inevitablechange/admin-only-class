      AI with Paul13

      실습 1 · 비밀 키 보관

      비밀 키는 배포 플랫폼의 환경변수에 넣어요

      키는 내 컴퓨터의 .env 파일에 있어서 GitHub에 올라가지 않아요. 그래서 배포 플랫폼(Netlify · Vercel · Cloudflare Pages 등)에도 따로 한 번 넣어 줘야 해요.

      1. 배포 플랫폼 → 내 사이트 → 환경변수 설정 메뉴
      2. Claude가 알려 준 이름과 값을 붙여 넣어요
      3. 다시 배포해요(Trigger deploy / Redeploy)
      넣을 키 목록 받기
      지금 쓰는 배포 플랫폼(Netlify/Vercel/Cloudflare Pages 등)의
환경변수에 넣어야 할 키를 표로 알려줘.
이름, 어디서 복사하는지, 공개돼도 되는 키인지까지.

      메뉴 이름이 다르면 화면을 캡처해서 "어디를 눌러야 해?"라고 물어봐요.

      과제 · 보안

      관리자 페이지는 보안이 더 중요해요

      이 세 가지만 지켜요

      • /admin은 내 계정만 들어와요
      • 데이터베이스는 아무나 읽거나 고칠 수 없어요
      • 비밀 키는 코드와 GitHub에 없어요
      규칙 한 번 적어 두기
      CLAUDE.md에 보안 규칙을 적어줘. 비밀 키는 .env와 배포 플랫폼에만,
관리자 기능은 로그인 확인 후에만, 작업이 끝나면 보안 점검하기.
      관리자 보안 점검
      보안 점검해줘. 로그인 없이 /admin에 들어갈 수 있는지, Supabase 데이터베이스를
아무나 읽거나 고칠 수 있는지, 비밀 키가 노출됐는지 확인하고 고쳐줘.
